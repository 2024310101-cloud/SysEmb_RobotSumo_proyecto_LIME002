# ROBOT SUMO

## Descripción General
Este proyecto consiste en el diseño, desarrollo e implementación de un Robot Sumo Autónomo de alta complejidad técnica, controlado mediante un microcontrolador STM32. El robot está programado para competir de manera autónoma dentro de un cuadrilátero circular (Dohyo), detectando la presencia y posición del rival para embestirlo y expulsarlo del área de combate, al tiempo que evita cruzar los límites del cuadrilátero.

El sistema procesa información en tiempo real procedente de sensores de proximidad para la ubicación del objetivo y sensores ópticos para la detección de bordes. Con base en esta lectura, el STM32 ejecuta rutinas de búsqueda, evasión y ataque, manipulando la velocidad y dirección del sistema de tracción a través de señales PWM.
